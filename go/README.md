# takeon-go (spike)

Go port of the Takeon determinism core. See `../docs/go-core-spike.md`. Tests need `../golden/*.json` (generated by `packages/engine/scripts/golden.ts`).

## Android

Kotlin wrapper over `takeon.aar`: see [android/README.md](android/README.md). `window` (terrain rectangle for renderers) is exposed on iOS/macOS, Android and `globalThis.takeon.window` in WASM.
